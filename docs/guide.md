# 渔情LiveBot · 使用说明

> **公益项目，请勿挪用收费 · BUG 反馈群：1092065806**

这是一个跑在自己电脑上的 B 站直播间助手：连上弹幕、记录事件、按规则答谢和播报，
页面上看数据、改配置，OBS 里可以用透明挂件。

> 账号登录、弹幕发送都走你自己的 B 站账号；工具不代替你登录，也不上传你的
> Cookie、日志和观众数据。

## 1. 安装

1. **不用单独装 Node.js**：安装包已经带了一份 Windows 便携 Node 22（`runtime\node`）。如果 `runtime` 被删掉，`install.bat` 会自动下载；也可以手动运行 `scripts\setup-node.bat`。
2. 把项目文件夹放在一个固定位置，例如 `E:\渔情`。
3. 双击 `scripts\install.bat`，它会检查 Node、创建目录、安装唯一的依赖 `ws`。

看到 `[DONE] Environment is ready.` 就可以了。

## 2. 登录 B 站

- 先启动服务（见下一节），再打开 `http://127.0.0.1:8900/login` 扫码。
- 扫码成功后房间会自动重连，不需要重启。
- 凭证只保存在本机 `data/auth.json`，不会提交到 git。

## 3. 启动 / 停止

根目录的 `启动渔情.bat` 是快捷方式，真正逻辑在 `scripts\`：

| 操作 | 命令 |
| --- | --- |
| 启动 | `scripts\start.bat` |
| 停止 | `scripts\stop.bat` |
| 重启 | `scripts\restart.bat` |
| 看状态 | `scripts\status.bat` |
| 开机自启 | `scripts\install-autostart.bat` |
| 取消自启 | `scripts\uninstall-autostart.bat` |

启动后打开 `http://127.0.0.1:8900`。

- `start.bat auto` 是计划任务用的模式：手动停过（存在 `logs\service.paused`）就不会被自动拉起。
- 日志在 `logs\service.out.log`，超过 5MB 会自动轮转。

## 4. 第一次配置

1. 页面右上角 **换房间**，填直播间号（短号也行），保存。
2. 确认页面上的账号、房间标题正确。
3. 先在 **演练模式**（dry run）下看一会儿：事件照常记录，但不会真的发弹幕。
4. 确认没问题后关掉演练模式。

## 5. 功能入口

- **插件**：礼物答谢、盲盒、SC、欢迎、关键词、定时播报、主动招呼、弹幕指令。
- **维护**：换账号、更新检查、更新镜像、诊断包、使用说明。
- **PK 情报**：看对面房间公开数据，PK 开始时自动播报对方情报。
- **点歌队列**：观众发「点歌 歌名」，页面里播放/完成/跳过。
- **付费用户榜**：按 uid 跨场次合并的付费记录，可设置大额/回访提醒。
- **战报**：场次、高光时间轴、下播战报海报、月报/季报。
- **OBS 挂件**：操作台顶部点「挂件」生成地址，复制到 OBS 的浏览器源（默认 `http://127.0.0.1:8900/overlay.html`）。

## 6. 更新

维护页会检查新版本：下载 → 校验 sha256/大小 → 重启并应用。
更新由独立进程执行，会先备份代码；启动失败会自动回滚。`data/` 永远不动。

如果直连 GitHub 失败（常见 8 秒超时），可以在维护页填「更新镜像」：

```
https://pub-1c052ae1726e4964913fac13a4cbd08f.r2.dev/yq
```

镜像只做转发，包仍然按清单里的 sha256 校验。

## 7. 常见问题

**端口被占用 / 启动失败**
先看 `logs\service.out.log` 末尾；确认 8900 没有被别的程序占着。

**检查更新 8 秒没响应**
本机到 GitHub 超时。配代理（`scripts\proxy.txt` 写代理地址后重启）或填更新镜像。

**换账号后没反应**
扫码成功后会自动重连；如果页面还显示旧账号，刷新页面即可。

**机器人不说话**
先看是不是还开着演练模式；机器人只在事件触发时说话（进场、关键词、SC、礼物、
主动招呼、定时播报），不会自己找话题。

## 8. 数据与备份

- 事件日志：`data/events/<房间号>/*.jsonl`
- 配置：`data/app.json`（自动保留 `app.json.bak`）
- 认证：`data/auth.json`
- 备份：`data/backups/`（更新时生成）

`data/` 不进 git，请自行备份这个目录。
